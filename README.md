# SmartCity Insight AI

## AI-Powered Urban Grievance Pattern & Root-Cause Analyzer

SmartCity Insight AI is an AI-assisted decision-support prototype designed to analyze urban grievance data and identify recurring complaint patterns, possible contributing factors, and areas requiring further human investigation.

## SDG Alignment

**SDG 11 — Sustainable Cities and Communities**

## Problem

Urban areas receive complaints related to waterlogging, drainage, waste, damaged roads, streetlights, public transport and noise. Similar complaints may occur across different locations and dates, making it difficult to identify recurring patterns manually.

## Solution

The project uses AI to:

1. Extract structured information from complaints
2. Classify complaints
3. Group similar complaints
4. Detect recurring patterns
5. Identify possible contributing factors
6. Generate an insight and action report for human investigation

## AI Workflow

Synthetic Complaint Data
↓
Information Extraction
↓
Complaint Classification
↓
Similar Complaint Grouping
↓
Pattern Detection
↓
Possible Root-Cause Analysis
↓
Insight & Action Report
↓
Human Verification

## Technologies Used

* IBM watsonx.ai Prompt Lab
* IBM Granite
* Python
* Streamlit
* CSV / Synthetic Dataset

## Prototype

The Streamlit prototype allows users to:

* Upload the synthetic grievance dataset
* Explore complaint categories
* View recurring patterns
* Examine evidence IDs
* Review possible contributing factors
* Review human verification recommendations
* Generate and download an insight report

## Dataset

The prototype uses **50 synthetic urban grievance records**.

No real citizen personal information is used.

## Responsible AI

* AI-generated factors are treated as possible contributing factors, not confirmed causes.
* Human verification is required before real-world action.
* Complaint frequency does not automatically represent actual severity.
* The system does not make government decisions.
* Synthetic demonstration data is used.

## Project Status

## Future Scope

Future development could include validated municipal datasets, maps, time-based analysis and additional urban indicators.
